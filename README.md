# Gourish Bhagat — Angular Portfolio

A modern, responsive developer portfolio built with Angular.

## Stack

- Angular 22
- TypeScript
- HTML5 / CSS3
- GitHub Actions
- GitHub Pages

## Development

```bash
npm install
npm start
```

Then open `http://localhost:4200`.

## Production build

```bash
npm run build
```

The production output is generated under `dist/gourish-portfolio/browser`.

## GitHub Pages

The repository includes `.github/workflows/deploy.yml`. Push the project to the `main` branch and the workflow will build and deploy the site.

Portfolio content is based on Gourish Bhagat's current professional resume.
